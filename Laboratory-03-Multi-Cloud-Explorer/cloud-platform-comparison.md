## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
Amazon Web Services (AWS) offers the broadest range of services, featuring over 200 fully functional products spanning compute, storage, databases, machine learning, and IoT. Its first-mover advantage has allowed it to build the deepest catalog of features and configuration options in the market. As a result, it remains the standard choice for complex, multi-faceted application deployments.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure provides the best native integration with Microsoft technologies and legacy corporate infrastructure. It allows seamless connection with tools like Active Directory, Windows Server, SQL Server, and Microsoft 365 through unified identity and hybrid solutions like Azure Arc. Organizations already invested in the Microsoft software stack benefit significantly from licensing discounts and smooth cloud migrations.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) is widely recognized as the leader in Artificial Intelligence and Kubernetes. Since Google originally created Kubernetes, Google Kubernetes Engine (GKE) remains the most advanced managed Kubernetes environment. Furthermore, GCP leverages Google's cutting-edge AI infrastructure, delivering tools like BigQuery and Vertex AI with native integration for modern LLMs.

### 4. Which cloud platform would you personally choose and why?
I would personally choose **Google Cloud Platform (GCP)** due to its modern, developer-friendly design and unmatched capabilities in container management and data analytics. Its global private network infrastructure offers excellent low-latency performance and simplified global networking compared to traditional subnet structures. Additionally, GCP's native focus on Kubernetes and AI tools makes it the most future-ready environment for modern cloud-native development.
