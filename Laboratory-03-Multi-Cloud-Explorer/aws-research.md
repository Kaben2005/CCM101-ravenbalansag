# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is a comprehensive and broadly adopted cloud platform provided by Amazon. Launched publicly in 2006, AWS offers over 200 fully featured services from data centers globally, spanning compute, storage, databases, networking, machine learning, and security.

## Global Infrastructure
AWS infrastructure is organized into physical geographical locations called **Regions**. Each Region contains multiple isolated and physically separated **Availability Zones (AZs)** connected with low-latency, high-throughput networking.
- **Regions:** 30+ physical locations worldwide.
- **Availability Zones:** 100+ AZs globally, each equipped with independent power, cooling, and physical security.
- **Edge Locations:** 400+ CloudFront Points of Presence (PoPs) to deliver low-latency content worldwide.

## Cloud Management Console
The **AWS Management Console** is a web-based graphical interface used to manage and access AWS resources. Features include:
- Centralized search for services, resources, and documentation.
- Integrated **AWS CloudShell** for running CLI commands directly from the browser.
- Customizable dashboard widgets for billing alerts, recent services, and system health.

## Four (4) Core Services
1. **Amazon EC2 (Elastic Compute Cloud):** Provides scalable virtual servers (IaaS) allowing users to run applications on demand.
2. **Amazon S3 (Simple Storage Service):** Scalable object storage service designed for 99.999999999% (11 9's) of data durability.
3. **Amazon RDS (Relational Database Service):** Managed relational database service supporting PostgreSQL, MySQL, MariaDB, Oracle, and SQL Server.
4. **AWS Lambda:** Serverless compute service that runs code in response to events without provisioning or managing servers.

## Three (3) Advantages
1. **Market Maturity & Depth:** Offers the broadest and deepest selection of cloud features and mature tooling in the market.
2. **Global Reach & Reliability:** Multi-AZ architecture ensures high availability, resiliency, and fault tolerance.
3. **Flexible Pay-As-You-Go Pricing:** Pay only for resources consumed, backed by flexible pricing options like Savings Plans and Reserved Instances.

## Typical Enterprise Use Cases
- **Web Application Hosting:** Running highly scalable, auto-scaling web platforms.
- **Big Data & Analytics:** Processing petabyte-scale data lakes using EMR, Athena, and Redshift.
- **Enterprise ERP Migration:** Migrating legacy SAP and enterprise software to the cloud.
