# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a leading enterprise cloud platform launched in 2010. Azure integrates seamlessly with existing Microsoft enterprise tools (such as Active Directory, Windows Server, and Office 365), providing IaaS, PaaS, and SaaS solutions across global datacenters.

## Global Infrastructure
Azure boasts one of the largest global footprints among cloud providers.
- **Regions:** 60+ declared regions globally in over 140 countries.
- **Availability Zones:** Fault-isolated locations within an Azure region providing independent power and networking.
- **Geographies:** Regional groupings defined by compliance and data residency boundaries.

## Cloud Management Console
The **Azure Portal** is an intuitive, web-based hub for managing all Azure applications and services.
- Features customizable visual dashboards using blades (sliding panel navigation).
- Embedded **Azure Cloud Shell** supporting both Bash and PowerShell.
- Integrated resource management via **Azure Resource Manager (ARM)** templates.

![Azure Portal Homepage](https://upload.wikimedia.org/wikipedia/commons/a/a8/Microsoft_Azure_Logo.svg)

## Four (4) Core Services
1. **Azure Virtual Machines:** Scalable on-demand virtual compute resources running Linux or Windows Server.
2. **Azure Blob Storage:** Massively scalable object storage for unstructured data such as files, images, and backups.
3. **Azure SQL Database:** Managed relational database engine based on the latest stable version of Microsoft SQL Server.
4. **Entra ID (formerly Azure Active Directory):** Cloud-based identity and access management service enabling single sign-on (SSO) and multi-factor authentication (MFA).

## Three (3) Advantages
1. **Seamless Microsoft Ecosystem Integration:** Native integration with Windows Server, Active Directory, SQL Server, and Microsoft 365.
2. **Hybrid Cloud Leadership:** Outstanding hybrid capabilities through **Azure Arc** and **Azure Stack**.
3. **Enterprise Compliance & Security:** Holds the industry’s broadest portfolio of security and regulatory certifications.

## Typical Enterprise Use Cases
- **Hybrid Identity & Active Directory:** Synchronizing on-premises Active Directory with cloud services.
- **Enterprise ERP & Database Hosting:** Running large-scale SQL Server and SAP production workloads.
- **AI & Machine Learning:** Enterprise integration with Azure OpenAI Services and Microsoft Copilot.
